# CyberRacer — NPM Setup Guide

**Local Three.js Installation with Webpack Bundling**

## ✅ What's New

- ✓ Three.js installed locally via npm (no CDN dependency)
- ✓ Webpack bundler for optimal bundling
- ✓ ES6 module support
- ✓ Development server with hot reload
- ✓ Production build optimization

## 🚀 Setup (3 Steps)

### Step 1: Install Node.js Dependencies

```bash
cd cyberracer
npm install
```

This installs:
- `three` — 3D graphics library
- `@mediapipe/hands` — Hand gesture detection
- `webpack` & `webpack-cli` — Bundler
- `@babel/core` — JavaScript transpiler

### Step 2: Build the Project

```bash
# Development build (with source maps)
npm run build

# Or watch mode (rebuilds on file changes)
npx webpack --watch
```

This creates:
- `frontend/dist/bundle.js` — Bundled JavaScript
- `frontend/dist/index.html` — Copy of HTML
- `frontend/dist/assets/` — Car models

### Step 3: Run the Game

#### Option A: Development Server (Hot Reload)
```bash
npm run dev
# Opens http://localhost:8000
```

#### Option B: Serve Manually
```bash
cd frontend/dist
python -m http.server 8000
# Open http://localhost:8000
```

#### Option C: With Python Backend (OBI Reasoning)
```bash
# Terminal 1: Backend
npm run start
# Runs: python backend/app.py

# Terminal 2: Frontend
npm run dev
# Serves on http://localhost:8000
```

## 🚨 Troubleshooting

### "webpack not found"
```bash
# Solution: Reinstall dev dependencies
npm install --save-dev webpack webpack-cli
```

### "THREE is not defined"
```bash
# Solution: Ensure index.js is imported in HTML
# Check: <script src="dist/bundle.js"></script>
```

### Bundle size too large
```bash
# Use production mode
npm run build -- --mode production

# Check what's bundled
npm install --save-dev webpack-bundle-analyzer
```

### Changes not reflecting
```bash
# Clear cache and rebuild
rm -rf frontend/dist node_modules
npm install
npm run build
```

## 🔐 Version Pinning

All versions are specified in `package.json`. To update:

```bash
# Update Three.js
npm install three@latest

# Update all packages
npm update

# Check for outdated packages
npm outdated
```

## 🌐 Without Webpack (Alternative)

If you prefer to skip webpack, you can:

1. Use ES6 modules directly in browser:
   ```html
   <script type="module" src="frontend/js/index.js"></script>
   ```

2. This requires:
   - Modern browser (Chrome, Firefox, Safari, Edge)
   - Importing modules with full paths
   - No minification/optimization
