🎮 GAME FEATURES

Hand Gesture Controls:
  🖐️  OPEN PALM       → Accelerate
  ✊   FIST            → Brake
  ☝️  POINT (INDEX)   → Steer Left
  👍  THUMBS UP       → Steer Right
  ✌️  PEACE (2 FING) → Drift

Game Features:
  • Real-time hand detection (30 FPS)
  • MediaPipe gesture recognition
  • Three.js 3D rendering (60 FPS)
  • OBI reasoning with 95.4% confidence gating
  • 9 different car models with lighting
  • Physics simulation (speed, acceleration, steering)
  • Live confidence scoring and reasoning transparency
  • Epistemic audit trail for interpretability
  • P2P multiplayer network support

═══════════════════════════════════════════════════════════════════════════

🧠 OBI REASONING ENGINE

Three-Step Rhetorical Reasoning:
  
  FACT:           Summarize raw gesture input
                  "Palm open, all fingers extended"
  
  JUSTIFICATION:  Analyze constraints and context
                  "User intent to increase velocity detected"
  
  RATIONAL:       Select action based on reasoning
                  "ACCELERATE"

Confidence Gating:
  • Threshold: 95.4% (μ + 2σ standard deviation)
  • Bias Parameter: 1 - confidence
  • Epistemic States: DIVERGING / UNCERTAIN / CONVERGED

🔌 API ENDPOINTS

GET    /health                Check server status
POST   /reason                Request OBI reasoning for gesture
POST   /session/start         Initialize game session
POST   /session/end           End game session
GET    /network/peers         List connected peers
POST   /network/register      Register as P2P peer

🚀 QUICK START

1. Install dependencies:
   pip install -r requirements.txt
   pip install obi

2. Start backend:
   python backend/app.py

3. Open frontend:
   • Direct: Open frontend/index.html in browser
   • Or serve: cd frontend && python -m http.server 8000

4. Click "START AUTHENTICATION" button

5. Show both hands to camera and use gestures to play!
